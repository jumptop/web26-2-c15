태그와 요소

HTML 페이지를 구성하는 각 부품을 `요소`라고 부름

태그는 이러한 요소를 만들 때 사용하는 작성 방법

요소는 객체라고도 부름

속성

속성은 태그에 추가 정보를 부여할 때 사용하는 것

예를 들어, <h1 title = "header">Hello HTML5</h1>와 같은 방식으로 사용했을 때 title이 속성 이름, "header"가 속성 값을 뜻한다.

주석

프로그램이 커지면 작성한 코드가 어떠한 의미를 가지는지 모르는 상황이 생길 수 있고, 이럴 때 코드의 의미를 설명하는 글을 주석이라고 부른다.

<!-- -->이러한 방식으로 작성하며, --사이에 글을 입력하면 이는 코드로 인식되지 않고, 통합 개발 환경에서만 확인할 수 있다.
