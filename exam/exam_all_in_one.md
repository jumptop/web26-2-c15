# Chapter 02 - 요약 및 연습문제 풀이

## 요약
1. HTML 페이지를 구성하는 각 부품을 `요소` 라고 한다.
2. `태그` 는 이러한 요소를 만들 때 사용하는 작성 방법이다.
3. 내용을 가질 수 있는 요소를 생성할 때 앞에 붙이는 태그를 `시작 태그`라고 하며, 뒤에 붙이는 태그를 `끝 태그`라고 한다.
4. `태그`에 추가 정보를 추가할 때 `속성`을 사용한다.
5. `주석`은 프로그램 실행에 영향을 미치지 않으면서 설명용으로 사용하는 코드를 말한다.
6. `내부 스타일`은 HTML 페이지 내부에서 `style`태그를 사용해 스타일시트를 직접 입력하는 방법이다.
7. `외부 스타일시트` 를 HTML 페이지에 불러오려면 `<link rel="stylesheet", href="style.css">` 태그를 사용한다.
8. `외부 자바스크립트`를 HTML 페이지에 불러오려면 `<script src="script.js"></script>` 를 사용한다.

# Chapter04 - 요약 및 연습문제 풀이

1. `입력 양식`은 사용자에게 정보를 입력받는 요소이다.
2. form 태그는 `method` 속성의 방식으로 `action` 속성 장소에 데이터를 전달한다.
3. `GET` 방식은 주소에 데이터를 입력해서 전달한다.
4. `POST` 방식은 GET방식과 달리 비밀스럽게 데이터를 전달한다.
5. `input` 태그에 `type` 속성을 지정해서 다양한 종류의 기본 입력 양식을 생성할 수 있다.
6. `radio` 버튼의 `name` 속성을 사용하면 여러 대상 중 하나만 선택하는 형태를 구현할 수 있다.
7. `select` 태그는 목록으로 보여 주는 항목 중 하나 또는 여러 개를 선택할 때 사용하는 입력 양식 요소이다.
	1. `select` 태그 내부에 `option` 태그를 넣어 선택 옵션을 지정할 수 있다.
	2. `<select multiple="multiple">` 속성을 지정하면 여러개의 `option`을 선택할 수 있다.
	3. `<optgroup label="label_name">` 태그와 속성을 지정하여 `option`을 하나로 묶을 수 있다.
8. `fieldset` 태그와 `legend` 태그를 사용하면 입력 양식을 그룹으로 묶고 이름을 지정할 수 있다.
9. `textarea` 태그는 시작 태그와 끝 태그 사이의 공백이나 tab 등 모든 글자를 인식하므로 붙여 사용해야 함.
10. `div`태그는 공간을 블록 형식으로 분할한다.
11. `span`태그는 공간을 인라인 형식으로 분할한다.
12. `시멘틱 웹`은 컴퓨터 프로그램이 코드를 읽고 의미를 인식할 수 있는 지능형 웹을 의미한다.

# Chapter05 - 요약 및 연습문제 풀이

1. `선택자`를 사용해 특정 HTML 태그를 선택하면, 선택한 태그에 원하는 스타일이나 스타일시트를 적용할 수 있다.
2. `style` 태그 내부에 CSS 블록을 입력해 작성한 코드를 `스타일시트`라고 합니다.
3. 웹 표준에 `아이디 선택자` 속성은 웹 페이지 내부에서 중복되면 안 된다는 규정이 있으므로 특정 태그 하나만 선택할 때 `아이디 선택자` 를 사용한다.
4. HTML 페이지 내부의 모든 h1 태그의 color 스타일 속성을 변경하려면 `태그 선택자`를 사용한다.
5. 클래스를 여러 개 사용할 때 `공백`으로 구분한다. (ex: \<p class=”item header”\>이중클래스\</p\>)
6. 계층 구조가 있는 태그에서 기준 태그보다 바로 한 단계 아래에 위치한 태그를 `자식(자손) 태그` 라고 하며, 기준 태그 아래에 위치한 모든 태그를 `후손 태그` 라고 한다.
7. `table` 태그에는 자동으로 `tbody` 태그가 추가되므로 `table` 태그의 요소를 선택할 때는 자손 선택자를  사용하지 않는 편이 좋다.
8. `반응` 선택자는 사용자가 특정 태그 위로 마우스 커서를 올리거나, 특정 태그를 클릭하여 생성되는 특정 상태를 선택한다.
9. `상태` 선택자는 입력 양식의 상태를 선택한다.
10. `구조` 선택자는 특정한 위치에 있는 태그를 선택한다.
11. `키워드`는 스타일 값으로 입력하면 해당 스타일이 자동으로 적용되도록 W3C에서 미리 정의한 단어이다.
12. CSS3의 크기 단위 중 `em`은 배수를 나타내는 단위이다.
13. `HEX` 코드 단위는 색상을 16진수로 표현한다.

# Chapter06 - 문제 요약 및 정리

1. `박스 속성`에는 margin, border, padding, width, height 속성이 포함된다.
2. 테두리 굵기는 `border-width`, 테두리 형태는 `border-style`, 테두리 색상은 `border-color`를 사용
3. `border-radius` 속성을 사용하면 박스의 테두리를 둥글게 만들 수 있다.
4. `display` 에 `none` 속성값을 적용하면 태그가 보이지 않는다.
5. `background-image` 속성은 배경 이미지를 넣을 때 사용한다.
6. `background-size` 속성은 배경 이미지 크기를 지정한다.
7. `background-repeat` 속성은 배경 이미지의 반복 형태를 지정한다.
8. `background-attachment` 속성은 배경 이미지를 화면에 고정한다.
9. `font-size` 속성은 글자 크기를 지정하고, `font-family` 속성은 글꼴을 지정한다.
10. `Serif` 글꼴은 끝이 뾰족한 글자이고, `Sans-serif` 글꼴은 모서리가 네모난 글꼴을 의미한다.
11. `font-style` 속성은 글자의 스타일(기울기 등)을 지정하고, `font-weight`는 글자의 굵기를 지정한다.
12. `text-align` 속성은 글자 정렬을 지정하고, `line-height` 속성은 글자의 높이를 지정한다.
13. `position` 속성은 요소의 위치 지정 형식을  설정할 때 사용한다.
14. `overflow` 속성은 내용이 요소 크기를 벗어나 모두 보여 주기 힘들 때 사용한다.
15. `box-shadow`속성은 박스에 그림자를 부여하고, `text-shadow` 속성은 글자에 그림자를 부여한다.
