시맨틱 태그로 레이아웃 나누기

HTML5 · 2026년 3월 24일

header, nav, section, article, aside, footer로 영역의 의미를 드러낸다. div만 쓰는 것보다 구조를 읽기 쉽고, 검색엔진·스크린리더도 이해하기 쉽다.

입력 양식(form) 기본

HTML5 · 2026년 3월 31일

form 안에 input(text, password, checkbox, radio), select, textarea를 넣는다. label의 for와 input의 id를 맞추면 글자를 눌러도 입력칸이 선택된다.

float와 overflow: hidden

CSS3 · 2026년 4월 28일

자식을 float 하면 부모 높이가 0이 된다. 부모에 overflow: hidden을 주면 float된 자식을 감싸 높이가 생긴다. (이 페이지의 #content도 같은 방법)

position으로 드롭다운 만들기

CSS3 · 2026년 5월 12일

부모 메뉴에 position: relative, 하위 메뉴에 position: absolute를 주면 하위 메뉴가 부모 기준으로 아래에 붙는다. 평소엔 display: none으로 숨긴다.

DOM 요소 선택

JavaScript · 2026년 11월 3일

document.querySelector('선택자')는 첫 번째 요소 하나, querySelectorAll은 모든 요소를 가져온다. 스크립트가 body보다 먼저 실행되면 요소를 못 찾는다.

jQuery .on() 이벤트 연결

JavaScript · 2026년 11월 17일

$(선택자).on('이벤트', 함수) 형태로 click, input, change, submit 등을 연결한다. $(부모).on('click', '자식선택자', 함수)처럼 쓰면 나중에 추가된 요소에도 동작한다(이벤트 위임).
